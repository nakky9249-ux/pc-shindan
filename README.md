# PC診断室

PC・パーツ・ゲーム関連ニュースをRSSから自動取得し、検索できる一覧として表示する静的サイトです。

## 自動更新
- GitHub Actions が3時間ごとにRSS/Atomフィードを取得します。
- 記事タイトル、配信元、公開日時、概要、元記事リンクを `news.json` に保存します。
- 取得前にRSSパーサーのユニットテストを実行します。
- `feeds.txt` に `表示名|RSS/AtomのURL` を追加すると配信元を増やせます。
- GitHub Actions の「Update PC news」から「Run workflow」で手動実行できます。

## GitHub Pages
リポジトリの Settings → Pages で Source を「Deploy from a branch」、Branch を `main`、フォルダを `/(root)` に設定してください。

## 注意
RSSの見出し・概要・リンクを利用する仕組みです。記事本文の全文転載はしません。AIによる独自記事の生成・要約には別途AI APIと実装が必要です。RSS配信元の利用条件を守ってください。


## おすすめ構成・価格確認・シミュレーター
- 低予算、AM5入門、フルHD、FPS、高FPS、WQHD、4K、配信・動画編集、AI制作など11種類の構成を掲載しています。
- 構成カードはパーツ別価格を展開でき、「この構成をシミュレーターに反映」で選択欄に反映できます。
- 簡単診断の結果もおすすめ構成データから選び、同じ参考単価で合計を計算します。
- シミュレーターでは選択パーツの仕様、互換性の注意、合計価格を確認でき、構成を保存・コピー・復元できます。
- パーツ構成と簡単診断は、サイト内の参考価格を使って合計を計算します。
- 各パーツから価格.comの検索結果を開き、最新の販売価格・送料・在庫を確認できます。
- 現時点では価格.comの実売価格をサイト内へ自動反映する公式APIの利用手段を確認できていないため、自動取得済みの価格としては表示しません。
- 簡単診断の内訳と詳細パーツ構成は同じ参考価格データを使います。購入時は、価格.comや各販売店で型番・対応規格・価格を確認してください。


## サイト品質チェック
- `tests/test_site.py` がHTMLのID重複、ページ内リンク切れ、未設定リンク、新しいタブを開くリンクの安全属性を確認します。
- インラインJavaScriptはNode.jsの構文チェックを実行します。
- おすすめ構成が11件あり、IDが重複していないことを確認します。
- トップページまたはテストの変更時にGitHub Actionsでテストします。
- これは静的チェックです。実ブラウザでの全端末表示、実パーツの物理寸法、価格のリアルタイム性までは保証しません。
