# PCラボ

予算や用途からPC構成を考えられる、PC初心者向けの静的サイトです。

公開サイト： https://nakky9249-ux.github.io/pc-shindan/

## 主な機能
- 予算・用途・ゲーム・解像度からおすすめ構成を診断
- 11種類のPC構成プリセットとフィルター
- CPU、GPU、マザーボード、メモリ、ストレージ、電源、ケース、冷却、OSの構成シミュレーター
- 構成の互換性に関する簡易チェック、合計参考価格、構成の保存・コピー・復元
- RSS/Atomを使ったPC・ITニュースの自動更新（配信元の画像メタデータ、または最新記事ページのOG画像を取得してサムネイル表示）
- BTOショップの公式サイトへの通常リンク
- PCラボについて、プライバシーポリシー、広告方針、お問い合わせページ

## 価格・構成の注意
- 表示価格はサイト内の参考価格です。実売価格を自動取得した値ではありません。
- 価格.comへのリンクは検索リンクです。価格.comの公式価格APIと連携しているわけではありません。
- 実際の価格・送料・在庫・保証・製品仕様は、購入前に販売店やメーカー公式情報で確認してください。
- 互換性チェックは簡易的な目安です。BIOS、ケース寸法、GPUの長さ、電源コネクタ、冷却性能などの物理的な適合をすべて保証するものではありません。
- FPSはゲーム、設定、解像度、ドライバー、シーンによって変わります。

## ニュース自動更新
- GitHub Actions が3時間ごとにRSS/Atomフィードを取得し、`news.json` を更新します。
- `feeds.txt` に `表示名|RSS/AtomのURL` を1行ずつ追加すると配信元を増やせます。
- Actionsタブの「Update PC news」から手動実行できます。
- RSSの見出し・概要・元記事リンクを紹介し、配信元が公開している画像メタデータをサムネイルとして表示します。記事本文の全文転載はしません。各配信元の利用条件を守ってください。

## GitHub Pages
リポジトリの Settings → Pages で Source を「Deploy from a branch」、Branch を `main`、フォルダを `/(root)` に設定してください。

## アフィリエイトについて
現時点のBTOショップリンクは通常の公式サイトへのリンクで、提携済みの広告リンクではありません。広告主・ASPの審査と承認を受けた後に、発行された専用リンクだけを設定してください。広告リンクを掲載する場合は、利用者が広告だと分かる表示をリンクの近くに設けます。手順は `AFFILIATE_SETUP.md` を参照してください。

## 品質チェック
- `tests/test_site.py` はHTMLのID重複、ページ内リンク切れ、未設定リンク、新しいタブを開くリンクの安全属性、主要ページ、広告表示の方針、11個のプリセット、構成データ、インラインJavaScript構文を検査します。
- `.github/workflows/update-news.yml` でRSS更新前にテストを実行します。
- 静的テストは、実ブラウザーでの全端末表示や、実パーツの物理的な互換性までは保証しません。
